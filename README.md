# Жуки

## Как нарисовать карту
1. `levels/level_01.tscn`, выдели ноду **Map** (TileMapLayer)
2. вкладка **TileMap** -> выбери тайл -> рисуй в окне сцены (Shift+ЛКМ - линия, ПКМ - стереть).
   - коричневый = дорога
   - с ямой = Spawn, красный = Base (обязательно по одному+ тайлу каждого)
   - камень/куст = декор, жуки по ним не ходят
3. Размер поля: 40x22 клетки (640x352 px)
4. Новый уровень Scene -> Save Scene As в папку `levels/`. Он сам появится в меню выбора
   В корне уровня можно поменять Bug Type, Bug Count, Zoom

## Как поменять жуков
- Спрайты: `art/bug_sheet.png` - горизонтальная полоса кадров, жук смотрит вправо
- Параметры (размер кадра, кол-во кадров, fps, скорость и т. д.): `data/bug_default.tres`
- Новый вид: ПКМ в файловой панели -> Create New -> Resource -> BugType
